# News Sentiment Analysis

This repository supports a three-part analysis of financial news and stock price data:

1. Exploratory data analysis of news headlines and publishers.
2. Technical indicator analysis on historical stock prices.
3. Sentiment-to-return correlation analysis.

## Project Layout

- `notebooks/` contains analysis notebooks.
- `src/` contains reusable Python helpers.
- `scripts/` contains small command-line utilities if needed.
- `tests/` contains automated checks.
- `.github/workflows/` contains CI configuration.
